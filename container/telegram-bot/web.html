  • /hermes pesquise gateways PIX para PHP com fontes · /hermes analise o README do projeto

  • /hermes sozinho mostra se ele está ligado. Para ligar: ./hermes-configurar.sh na VPS.

PERGUNTAS FREQUENTES

  
Qual a diferença entre /modelo e /jarvis:modelos?
   /modelo troca o modelo da conversa principal (o orquestrador que fala com você). /jarvis:modelos escolhe o
   perfil dos agentes do projeto: econômico (quase tudo em Haiku/Sonnet), equilibrado (Opus só no arquiteto) ou máximo
   (Opus nos executores e no revisor). Recomendação: conversa em sonnet e perfil equilibrado.

  
Quando vale usar o Opus ou o Fable?
   Opus: mudanças em pagamento, permissões, arquitetura nova, bug que o Sonnet não resolveu em duas tentativas (o Jarvis já sobe de
   modelo sozinho depois de 2 falhas). Fable: só em problemas realmente difíceis; custa o dobro do Opus. Para uma única tarefa,
   prefira marcar [modelo:opus] no título da tarefa a trocar tudo.

  
O gateway aceita todos esses modelos?
   Depende do provedor. Se /modelo fable der erro, o gateway não oferece esse modelo ou usa outro nome. Nesse caso use o ID
   completo que o provedor informar (ex.: /modelo claude-fable-5-2) ou mapeie os apelidos no .env.claude com
   ANTHROPIC_DEFAULT_OPUS_MODEL, ANTHROPIC_DEFAULT_SONNET_MODEL e ANTHROPIC_DEFAULT_HAIKU_MODEL.

  
Meu gateway tem mais modelos. Como uso?
   Clique em 🛰️ Ver modelos do meu gateway acima (ou mande /modelos): o Jarvis pergunta ao gateway a lista atual.
   Depois use /modelo <ID> com o nome exatamente como aparece. Para os agentes usarem outro modelo, mapeie os apelidos
   no .env.claude (ANTHROPIC_DEFAULT_OPUS_MODEL=<ID>, idem SONNET e HAIKU) e recrie os serviços.
   Modelos que não são Claude podem falhar com as ferramentas (editar arquivos, rodar comandos); teste antes num projeto simples.

  
O que é o Hermes e quando usar?
   É o Hermes Agent, da Nous Research (código aberto). No Jarvis ele é um ajudante: faz pesquisas longas, compara opções e
   dá segunda opinião. Use /hermes <pedido>; os agentes também podem consultá-lo sozinhos. Ele usa o mesmo gateway
   (o gasto entra na mesma conta) e responde um pedido por vez. Ele não altera projetos, não usa seu GitHub e não tem porta aberta
   na VPS. Se /hermes disser que não está ligado, rode ./hermes-configurar.sh dentro de container/.

  
Por que o Hermes não usa o modelo da própria Nous?
   O que aprende e evolui é o agente Hermes (memória, skills que ele cria, histórico), não o modelo. Isso funciona igual com o
   Claude do seu gateway, que hoje programa e usa ferramentas melhor que os modelos Hermes. Se quiser o modelo e as ferramentas da Nous
   (busca, navegador, voz e imagens), rode ./hermes-configurar.sh --nous: precisa de conta no Nous Portal, com cobrança à parte.
   Para voltar ao gateway: ./hermes-configurar.sh.

  
Dá para trocar a voz do Hermes (ou do Jarvis)?
   Sim. No .env.claude: HERMES_VOICE= para o Hermes (padrão: pt-BR-ThalitaMultilingualNeural) e
   TTS_VOICE= para o Jarvis (padrão: pt-BR-AntonioNeural). Outras opções: pt-BR-FranciscaNeural,
   ou uma voz multilíngue como en-US-AndrewMultilingualNeural (fala português com sotaque). Para deixar mais grave ou agudo:
   HERMES_VOICE_TOM=-6Hz ou +4Hz. Depois: docker compose --profile web --profile telegram up -d.
   O Hermes fala as respostas do /hermes, exceto com 🔊 em "nunca".

  
O que são as linhas no cérebro?
   São os "pensamentos" do Jarvis: cada agente trabalhando acende uma região (arquiteto e revisor: frente; desenvolvedor e android: topo;
   dba e documentador: lateral; testador: cerebelo; explorador: parte de trás; deploy: tronco; Hermes: topo de trás, em dourado) e as
   linhas viajam entre as regiões. Quanto mais trabalho, mais linhas.

  
O Hermes testa como um usuário de verdade?
   Sim, nas tarefas com tela ou site: depois do testador, o Jarvis liga a prévia (👁) e pede ao Hermes para usar o sistema como um
   cliente e relatar o que quebrou. Cada problema vira tarefa e é corrigido e conferido. Você também pode pedir direto:
   /hermes teste como usuário o cadastro em http://jarvisweb:8081. Para clicar em telas ele precisa do navegador
   (vem com --nous); sem ele, testa lendo as páginas.

  
O que é o escritório (🏢)?
   Uma planta com uma sala para cada agente: quando ele trabalha, a sala acende, o robô se mexe e o balão mostra o que está fazendo.
   A sala de comando é o Jarvis, a consultoria é o Hermes, e à direita fica o quadro com as rotinas automáticas e os resultados.

  
Como criar rotinas (n8n)?
   Na VPS, rode ./automacoes-configurar.sh uma vez e publique na VPN com
   sudo tailscale serve --bg --https=5678 http://127.0.0.1:5678. Abra o n8n pelo botão ⚙ no escritório, crie o usuário e
   ative os fluxos de exemplo (pesquisa semanal, check-up diário, segurança semanal, alerta de erro). Para criar outros, copie um
   exemplo e troque o texto: as ações possíveis são hermes, jarvis (só analisa, testa e relata),
   pesquisar, ideia e avisar (Telegram).

  
Uma rotina pode alterar meu código ou publicar?
   Não. Em rotina, o Jarvis roda sem as ferramentas de edição e com commit, push, deploy, banco e envio de arquivos bloqueados; ele só
   devolve um relatório com sugestões. O Hermes continua só lendo. Para aplicar uma sugestão, peça você mesmo no painel.

  
O que é o /tendencias?
   Mostra o que as pessoas estão falando de um tema nos últimos 30 dias no Reddit, Hacker News, GitHub e Polymarket,
   ordenado por engajamento (curtidas, comentários), e salva um resumo em português na base (📈 tendências).
   Ex.: /tendencias gateway pix. Termos em inglês costumam trazer mais resultados.
   Usa o motor da skill last30days (código aberto) num ambiente isolado: sem suas chaves, sem cookies do navegador e
   sem publicar nada. O Hermes lê os resultados na base de conhecimento.

  
Como funciona o atendimento no WhatsApp (📱)?
   Usa o WhatsApp Web (WAHA) no número da empresa: cada mensagem passa pelo n8n e o Jarvis responde com base na
   base de respostas (📱), usando um modelo rápido e sem ferramentas (o cliente não consegue fazer o robô agir).
   Se o cliente pedir um atendente, reclamar, ou o assunto não estiver na base, você é avisado no Telegram e o robô se cala naquela
   conversa. Quando você responde pelo WhatsApp, o robô também se cala por 12 h; escreva #bot na conversa ou
   /devolver <número> para devolver. Comandos: /atendimento (status, on, off), /assumir.
   Atenção: não é a API oficial da Meta; use um número só da empresa, só para responder (nada de mensagens em massa),
   porque o WhatsApp pode bloquear números com uso automatizado.

  
Como gastar menos?
   Conversa em sonnet, perfil equilibrado, /compactar quando a conversa ficar longa, /novo ao mudar de
   assunto, demandas pequenas e claras, e /custo para acompanhar. Rodar 2 projetos ao mesmo tempo soma o gasto dos dois.

  
Os agentes não estão trabalhando, o que faço?
   Veja a caixa ao lado do holograma: ela mostra cada passo e o agente ativo. Se o Jarvis respondeu sem usar agentes numa demanda de
   código, peça de novo citando o fluxo (ex.: use o explorador e o revisor) ou use /jarvis:jarvis <pedido>.

  
Perdi a conversa ao trocar de projeto?
   Não. Cada projeto guarda o seu histórico; ao voltar para ele, a conversa reaparece. /novo começa do zero só no projeto atual.
